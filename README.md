# 果蝇乐园

Windows 桌面果蝇。仓库：[pyd021226/fly-paradise](https://github.com/pyd021226/fly-paradise)

**两份安装包，不同的模式。** 下载：[Releases](https://github.com/pyd021226/fly-paradise/releases/tag/v0.3.1)

| 文件 | 给谁用 |
|---|---|
| **fly-paradise-setup-0.3.1.exe** | 果蝇乐园。自己养，成虫最多 12 只，12 只全绿通关。开机启动默认关。 |
| **fly-paradise-welfare-setup-0.3.1.exe** | 果蝇乐园造福版。适合装到朋友的电脑。开机默认自启动。产卵更多，数量无上限。 |

## 源码运行

```
npm install
npm start
```

造福版预览：`npm run start:annoy`

## 打包

```
npm run dist
npm run dist:annoy
```
